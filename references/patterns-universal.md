# Universal Patterns — any language

Use this file when the text is in a language without its own `patterns-<code>.md`.
Priority order for languages in this skill: **Indonesian (full), English (full), then
every other language through this file.** These rules hold across languages because they
describe structure and substance, not vocabulary.

Work in the target language. Do not draft in English and translate; that creates calques.

## §1 Language-independent tells (fix in every language)

1. **Topic-announcing opener.** The first sentence says the topic is important or modern. Delete it.
2. **Empty intensifiers.** The local equivalent of "very", "truly", "extremely" stacked on claims with no evidence.
3. **Abstract praise words.** Local equivalents of innovative, comprehensive, seamless, optimal, robust, holistic. Replace with what the thing does.
4. **Nominalization.** "carry out an analysis" instead of "analyze". Prefer the verb in languages that allow it.
5. **Forced triplets and symmetric paragraphs.** Use real counts; vary length.
6. **Mini-conclusion at the end of each paragraph.** Delete.
7. **Recap ending** outside formal papers. Delete.
8. **Fake enthusiasm and exclamation marks.** Delete.
9. **Unsourced authority.** "Experts say" / "studies show" in any language. Name the source or cut.
10. **Emoji and decorative symbols.** Remove unless the brand voice uses them.
11. **English calques.** "navigate challenges", "harness the power", "landscape", "ecosystem", "in the realm of" translated word for word. Use the native expression.
12. **Mixed register / form of address.** Pick one (formal vs informal "you") and hold it.

## §2 Per-language conventions to respect (check before rebuilding)

Ask yourself, for the target language:

| Convention | Examples |
|---|---|
| Formal vs informal address | de: Sie/du · fr: vous/tu · es: usted/tú · ja: keigo levels · ko: -습니다/-요 · jv: krama/ngoko · su: lemes/loma |
| Official spelling authority | id: KBBI/EYD V · de: Duden · fr: Académie/Larousse · es: RAE · pt: Acordo Ortográfico · ms: DBP |
| Number formatting | decimal comma (id, de, fr, es, pt) vs point (en, ja, zh) · thousands separator |
| Punctuation | fr: space before `: ; ? !` · es: `¿ ¡` · zh/ja: full-width `，。` · de: „quotes" |
| Script and direction | ar, he, fa, ur: right-to-left · keep numerals as the reader expects |
| Academic voice | Some traditions favor impersonal/passive (id, de, fr); others accept first person (en) |
| Sentence length norms | Longer sentences are normal in de, fr, es academic prose; still split anything hard to parse aloud |

If you are not confident about a convention, keep the input's existing choice rather than guessing.

## §3 Regional languages of Indonesia

For Javanese, Sundanese, Balinese, Minangkabau, Bugis, and others: keep the speech level
the user chose (e.g. krama vs ngoko), keep local terms untranslated, and do not "correct"
toward Indonesian. If the text mixes Indonesian and a regional language on purpose, keep
the mix.

## §4 Confidence rule

For languages where your fluency is weaker, do less: cut clear filler, fix structure, and
leave word choice alone. State in one line that a native speaker should review. A light
correct edit beats a heavy unnatural one.
