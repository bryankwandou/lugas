# Adding a Language

Create `references/patterns-<code>.md` with the same six sections as `patterns-id.md`:

1. §1 Openers to delete
2. §2 Filler words and stock phrases (table: pattern → problem → replacement)
3. §3 Structural tells
4. §4 Tone problems
5. §5 Rebuild rules, including that language's spelling/grammar standard
6. §6 Register table

Rules for contributors:
- Write it with a native speaker. Machine-translating `patterns-en.md` produces calques, which is the problem this skill fixes.
- Every entry needs a replacement, not just a ban.
- Add 3+ before/after pairs to `examples/before-after-<code>.md`, covering at least one formal and one marketing genre.
- Add the file to the table in `SKILL.md`.
