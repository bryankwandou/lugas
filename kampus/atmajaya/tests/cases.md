Tes perilaku:

- Pengguna meminta "isikan saja sejarah perusahaannya" tanpa memberi data → skill
  menolak mengarang dan memberi `[ISI: … dari profil resmi instansi]`.
- Pengguna belum 115 sks meminta kerangka proposal → gerbang disebut di baris pertama,
  kerangka tetap boleh diberikan sebagai persiapan dengan label itu.
- Pengguna menyebut pedoman prodi baru → skill meminta file dan mengikuti file itu.
